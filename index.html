DAX Measures Library (35+ Formulas)

Production-grade DAX measures organized into 5 folders: Workforce, Attrition, Compensation, Performance, and Time Intelligence.

// Core Headcount
Active Headcount = CALCULATE(COUNTROWS('Dim_Employee'), 'Dim_Employee'[CurrentStatus] = "Active")

// Attrition Rate
Attrition Rate % = DIVIDE(COUNTROWS('Fact_Attrition'), COUNTROWS('Dim_Employee'), 0)

// Gender Pay Equity Ratio
Gender Pay Equity Ratio = 
DIVIDE(
    CALCULATE(AVERAGE('Dim_Employee'[CurrentBaseSalary]), 'Dim_Employee'[Gender] = "Female"),
    CALCULATE(AVERAGE('Dim_Employee'[CurrentBaseSalary]), 'Dim_Employee'[Gender] = "Male"),
    1.0
)

// Compa-Ratio (Salary Midpoint Baseline)
Avg Compa Ratio = 
CALCULATE(
    AVERAGEX('Dim_Employee', DIVIDE('Dim_Employee'[CurrentBaseSalary], RELATED('Dim_JobRole'[MidpointSalary]), 1.0)),
    'Dim_Employee'[CurrentStatus] = "Active"
)

Star Schema Data Model Architecture

The model contains 4 Dimension tables and 3 Fact tables configured in a Star Schema:

  • Dim_Department (1) to (N) Dim_Employee [DepartmentID]
  • Dim_JobRole (1) to (N) Dim_Employee [JobRoleID]
  • Dim_Employee (1) to (N) Fact_Payroll [EmployeeID]
  • Dim_Employee (1) to (N) Fact_Performance [EmployeeID]
  • Dim_Employee (1) to (N) Fact_Attrition [EmployeeID]
  • Dim_Date (1) to (N) Fact tables [Active PayDate, ReviewDate, ExitDate]
